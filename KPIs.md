# KPIs — Marketing Workflow Analytics

## Campaign KPIs
- CPA (Cost per Acquisition)
- CTR (Clicks / Impressions)
- CPC (Spend / Clicks)
- Conversion Rate (Conversions / Clicks)
- ROI = (Revenue - Spend) / Spend

## Workflow Operations KPIs
- Fulfillment_Duration (minutes)
- SLA_Met (%)
- MTTR (Mean Time To Resolution) in minutes
- Incident_Count by severity
- Throughput (requests/day)
- Backlog size

## Alerts / Automation thresholds
- SLA failure probability > 0.6 -> escalate
- Incident priority = HIGH -> immediate assign
