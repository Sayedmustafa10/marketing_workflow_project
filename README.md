# Marketing Workflow Analytics & Process Optimization

Quickstart:
1. Create venv and install: `pip install -r requirements.txt`
2. Generate synthetic data: `python notebooks/generate_synthetic_data.py`
3. Load DB: `python src/etl/load_data.py`
4. Transform data: `python src/etl/transform.py`
5. Run automation demo: `python src/automation/incident_handler.py`
